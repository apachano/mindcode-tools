## [0.1.0] - 2026-06-02

- Added Mindcode language registration for `.mnd` files.
- Added TextMate grammar for Mindcode syntax highlighting.
- Added language configuration for comments, brackets, auto-close pairs, folding, and indentation rules.
- Added initial Mindcode snippets for basic autocomplete.
